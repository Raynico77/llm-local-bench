# Сравнение локальных LLM: протокол и результаты

Замеры 04–06.11.2026 на одной рабочей станции (RTX 5090 + RTX 3090 Ti), llama.cpp, один протокол для всех моделей. Эталон общего набора — Qwen3-VL-30B-A3B-Instruct Q6_K.

## Стенд и протокол

Все модели запускались одним способом: отдельный llama-server в контейнере, одна карта, одни и те же наборы и нагрузки.

| Что | Значение |
| --- | --- |
| Карта A | NVIDIA RTX 5090, 32 607 МиБ |
| Карта B | NVIDIA RTX 3090 Ti, 23 028 МиБ (к ней подключены мониторы, фон 1,1–2,2 ГиБ) |
| ОЗУ для экспертов MoE | ~55 ГиБ, видимых в WSL2 |
| ОС | Windows 11 + WSL2 Ubuntu, Docker, NVIDIA Container Toolkit |
| Движок «старый» | llama.cpp build 10680 (образ llama-swap `:cuda`, llama-swap v251) |
| Движок «новый» | образ llama-swap `unified-cuda13@sha256:54143293…`, llama-server `0.9.0-dev`, commit `330f018` |
| Контекст, внимание | `--ctx-size 65536 --flash-attn on --jinja`, все слои на GPU (`-ngl 999`) |
| KV-кэш | q8_0 (K и V); у Qwen3.8-27B — f16, как в её рабочей конфигурации |
| Эксперты MoE в ОЗУ | `--n-cpu-moe 999` (только где указано) |
| Рассуждение | выключено: `--reasoning-budget 0` + `chat_template_kwargs: {enable_thinking: false}`; где включено — указано |

**Наборы задач**

- **Общий набор:** 57 задач с автоматическим вердиктом (сравнение по ним) и 37 задач на ручную оценку (в сравнение не входят).
- **Код:** 20 задач — одна функция Python 3 (stdlib) со скрытыми тестами, pass@1, температура 0,2, до 1 500 токенов. Код модели проходит статический запрет (сеть, процессы, удаление, eval/exec) и выполняется в отдельном процессе без сети: `python3 -I`, пустое окружение, 20 с, 1 ГиБ.
- **Зрение:** 68 кадров, 121 размеченный объект трёх классов, совпадение рамки при IoU ≥ 0,3, кадр режется на плитки 3×2.

Наборы закрытые и в репозиторий не входят.

**Скорость:** две нагрузки по 3 раза, в таблицах медиана и [мин–макс]. Короткая — промпт ~26 токенов, длинная — промпт 6,8–9,6 тыс. токенов и ответ 512 токенов. tg — генерация, ток/с; pp — обработка промпта.

**Статистика:** точный тест McNemar по задачам, где вердикты двух моделей разошлись: «A:B» — сколько задач решила только первая и только вторая модель.

## Зрение

Модель, обученная на зрение, находит столько же объектов, но даёт в 3,5 раза меньше ложных срабатываний и работает в 4 раза быстрее. Вопрос закрытый по классу («есть ли на кадре X; если да — рамки»), ответ JSON, плитки 3×2, рассуждение выключено.

| Показатель | Qwen3-VL-30B-A3B-Instruct Q6_K + mmproj (5090) | Qwen3.8-27B UD-Q4_K_M + mmproj F16 (3090 Ti, ctx 16K) |
| --- | --- | --- |
| Полнота, все 121 объект | 0,636 (77) | 0,612 (74) |
| — надписи на зданиях, 75 | 0,760 | 0,707 |
| — этикетка на бутылке, 21 | 0,952 | 1,000 |
| — микрофон-удочка у края кадра, 25 | 0 | 0 |
| Ложные срабатывания | 15 | 53 |
| Время на кадр (6 плиток) | ~3,5 с | ~14 с |
| VRAM с фоном, МиБ | — | 18 716 |

McNemar по полноте: 9 расхождений, p = 0,51. Обе модели пропускают одно и то же: «оба пропустили» 0,339 против 0,141 при независимости (отношение 2,4), поэтому вторая модель как перекрёстная проверка не помогает. Время для Qwen3-VL — из прогона 02.11.

## Ограничения

- Наборы малы: при 57 и 20 задачах разница в 1–3 задачи статистически не различима. p = 1,0 значит «разницы не видно», а не «разницы нет».
- Каждая модель прогнана один раз (pass@1). Повторяемость вердиктов не мерилась.
- Эталон общего набора переснимался в каждом прогоне и давал 49–52 из 57. Сравнение ведётся с эталоном того же прогона.
- Рассуждение выключено везде, кроме отмеченных строк. Для моделей, сильных в рассуждении, это занижает качество: у Qwen3.8-27B оно вырастает с 43 до 53.
- Кванты разные (Q2…Q6, NVFP4, MXFP4). Сравниваются конкретные файлы, а не модели вообще.
- Наборы закрытые, на русском языке и под свои задачи. С публичными бенчмарками цифры не сравнимы.
